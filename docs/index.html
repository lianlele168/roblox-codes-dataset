Roblox Game Codes Dataset

527 verified redeem codes across 19 Roblox games · multi-source checked · CC BY 4.0

A community dataset of Roblox game redeem codes, extracted from the robloxwikihub.com network of fan-made wikis. Every code was cross-checked against at least two independent public sources in September 2026; rewards use the publisher wording, and undocumented rewards are marked as such instead of guessed.
